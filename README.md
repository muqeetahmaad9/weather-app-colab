### 📖 Overview

Fetches live weather for any city from the OpenWeather API and prints current conditions. Written to run in Google Colab or locally.

### ✨ Features

- City lookup against the OpenWeather API
- Temperature, humidity and conditions in metric units
- Runs in Colab with no setup

### 🚀 Getting Started

```bash
pip install requests
# add your OpenWeather API key, then:
python weather_app.py
```
